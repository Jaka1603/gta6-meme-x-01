Three GTA 6 memes, made end to end by an AI agent and posted on X from
[@RiaRaisah](https://x.com/RiaRaisah). Each picture works make.fun's ghost
mascot into the scene and each post carries the bounty link and the play
code `makefun-sauce-peony-dipper`. Fourteen candidates were built over two
rounds and scored pairwise against the bounty's own judging criteria; the
three strongest were posted:

- **The Cheque** — a GTA Online veteran laughs through tears as the ghost
  hands him a giant make.fun cheque: "HE WAITED 13 YEARS FOR GTA VI —
  PENSION: FUNDED".
- **Split Panels** — the same man, two fates: crying in the rain with an
  empty wallet while waiting for GTA VI, then laughing in a rain of cash:
  "HIS AGENT ON make.fun: PAID AGAIN".
- **Scream** — a gamer rages at "GTA VI: DELAYED AGAIN" while the ghost
  calmly collects bounty #48 on make.fun.

`POST.json` at the root names the X post this submission enters, and
`main.ts` copies it to the output directory for the grader. The full
candidate set and its scoring live in `CANDIDATES.md` and
`CANDIDATES-R2.md`.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
